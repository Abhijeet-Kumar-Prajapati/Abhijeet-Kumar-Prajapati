### 🌐 Ionic ToolKit — All-in-One Student Toolkit

A single-page **PWA** bundling every tool a student needs in one place — Calculator,
Library Management, Snake Game, DSA Visualizer, Matrix Operations, Coding Platform,
AI Chat and an in-app Browser. Each tool ships in a **Basic** and an **Advanced** version.

- 🧮 Scientific calculator with memory keys and DEG/RAD mode
- 📚 Library management with add / edit / delete and CSV export
- 🐍 Snake game with a live speed test
- 📊 DSA visualizer for array operations
- 🔢 Matrix operations — add, multiply, transpose, determinant, max/min
- 💻 Coding platform with Python / JavaScript / C++ problems
- 📱 Installable as a PWA — works offline, zero dependencies

### ☕ Web Media Player

A responsive **single-file** web media player for local audio and video, with playlist
controls, playback speed, volume and brightness adjustment, and fullscreen support.

- ⌨️ Keyboard shortcuts — `Space` play/pause, `←` `→` seek, `↑` `↓` volume
- 📋 Multi-file playlist with auto-advance
- 📱 Fully responsive, **zero dependencies**

### ☕ Java Practice Programs — 40 Programs

A structured collection of **40 Java programs** covering Data Structures & Algorithms,
OOP concepts and small projects — BubbleSort, MergeSort, QuickSort, DFS/BFS,
Dijkstra, Kruskal, Huffman, Inheritance, Method Overloading/Overriding,
Exception Handling and more.

- ⚙️ **Automated CI** — every push compiles and runs all 40 programs
- 🧭 **All-in-One launcher** — run any program by number, category or search
